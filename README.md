# Atividade 1 – Rocket Lab Dados

Resolução da atividade de introdução ao PySpark: joins, criação de colunas, `groupBy` e funções de janela, usando uma base de cartas do FIFA Ultimate Team. No final, o desafio é montar o Dream Team do Brasil no 4-4-2.

## Arquivos

- `atividade_1.ipynb` – notebook com os exercícios resolvidos
- `data/` – bases usadas na aula (`fut_players_data.csv`, `metal_bands.csv` e `pokemon_data.csv`)

Python, PySpark e Databricks.
